# Experiment 0139 — the MMA is still free, and the 0135 decoder's pass is inside its own variance

Status: **F4-1 STEP 1 PASSES.** Feeding the PRMT successor's output into the
native SM86 MMA costs **0.63% and 0.64%** on the two production shapes, so the
tensor op remains effectively free even with the decoder within 1.9% of the
read floor. The candidate retains **27–28% of the gate's time budget** for
everything it has not yet built. Separately, this experiment identifies a
**cold-boost warm-up artefact** in the first process of an unlocked run, which
reads an ALU-bound arm 8–13% low; the median already rejects it, and experiment
0138's gate result stands.

Operating point: **experimentation** — a single RTX 3090, 350 W, stock unlocked
clocks, second card idle.

## Question and contract

Hypothesis: the MMA that the successor decoder exists to feed is still free at
the successor's operating point.

This had to be re-measured rather than inherited. Experiment 0136 found the MMA
free, but it measured that with the 0135 decoder, which had 1.6x of ALU slack
for the tensor op to hide inside. The successor removed that slack — it sits at
831.59 GB/s against an 847.79 GB/s read floor — so a cost that was previously
invisible could now be decisive. The contract's exact next step named this as
F4-1's first gate for exactly that reason.

Gate: if the MMA costs enough to push the candidate near the >600.0 GB/s parity
threshold, the budget must be rebuilt before any prepack work.

Correctness: unchanged from 0137 — 0 mismatches on both the 0135 and successor
oracles, all runs, both shapes. This arm is a **timing ceiling only**; the arena
is not in fragment order, so no correctness claim attaches to it.

## Implementation note

Each 32-bit code word decodes to exactly four BF16 pairs, which is exactly one
`m16n8k16` A fragment. The feed is therefore one
`mma.sync.aligned.m16n8k16.row.col.f32.bf16.bf16.f32` per word with **no
repacking between decoder and tensor op** — the decoder's output registers are
the MMA's operand registers. That is transferable-thesis item 3 realised end to
end. Register cost is 36 for the MMA arm against 37 for the decode-only arm,
with zero spills, zero shared memory and zero barriers.

## A warm-up artefact in the first process, and why the gate still stands

Experiment 0138 reported that the 0135 decoder clears the parity gate at
unlocked clocks, at medians of 621.71 and 604.09 GB/s. **That stands.** An
initial reading of the run spread as stochastic variance was wrong, and the run
order shows why:

| Shape | Experiment | Run 1 | Run 2 | Run 3 | Runs 2–3 spread |
|---|---|---:|---:|---:|---:|
| `gate_up_w1` | 0138 | **548.6** | 624.7 | 621.7 | 0.5% |
| `down_w2` | 0138 | **593.5** | 604.1 | 613.0 | 1.5% |
| `gate_up_w1` | 0139 | **546.4** | 627.7 | 627.7 | 0.0% |
| `down_w2` | 0139 | **575.1** | 624.7 | 618.8 | 1.0% |

In every case the low value is the **first** process, and runs 2 and 3 agree to
within 1.5%. This is not spread, it is a systematic **cold-boost ramp**:
unlocked, the card idles at 210 MHz, and the first process pays the ramp to
boost while later ones start warm. The DRAM-bound arms do not show it because
they do not depend on core clock.

The median of three interleaved processes — which is exactly what the contract
specifies — rejects that single outlier by construction. **The 0135 decoder's
parity-gate pass at the experimentation operating point is real**, and so is
the successor's much larger one.

The finding here is therefore a **protocol** note, not a verdict caveat:

> At the unlocked experimentation operating point, the first process of a run
> measures an ALU-bound arm on a still-ramping clock and reads 8–13% low. The
> median already handles it, but any experiment quoting individual runs, or
> using fewer than three processes, must discard or warm the first one. A
> DRAM-bound arm is unaffected.

Locked at 1605 MHz the same decoder measured 514.02, 514.02, 514.02 GB/s with
0.0% spread, because there is no ramp to pay. The experimentation point trades a
warm-up process for silicon-accurate numbers, which is the right trade and a
cheap one.

## What this does not establish

- Still not an F4-2 result. No fragment prepack, no activation fragment feed,
  no output publication, no split-K, and the arena is not in fragment order.
- The B fragment in this arm is a constant, not a real activation. A real
  activation feed adds loads this arm does not perform.
- No M curve, and nothing about FP8 or D-F8-GATE.
- The group-32 scale-to-K binding remains unproven; no probe has yet crossed a
  group boundary in fragment order.
